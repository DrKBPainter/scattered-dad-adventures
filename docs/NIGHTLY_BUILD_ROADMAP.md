# SHATTERED DAD ADVENTURE — NIGHTLY BUILD ROADMAP

Drives the automated 11:00 PM ET nightly build. Each night: complete **exactly ONE
unchecked chunk**, run diagnostics, bump the version, sync the data catalogs, check
the box, append a changelog line, and STOP. Small runs by design; err toward more nights.

- **Game files:** `ShatteredDadAdventure.html` (shell) + `js/config.js → sprites.js → data.js → game.js → render.js → ui.js → input.js` (load order matters), currently v0.11.0
- **Data catalogs:** `data/*.txt` are auto-generated mirrors. Regenerate with `node tools_export_data.js` after ANY data change.
- **Version:** bump `GAME_VERSION` in `js/config.js` (patch=content, minor=systems).
- **Data arrays** in `js/data.js`: CREATURES, BOSSES, WEAPONS, ARMORS (slot), CHARMS (wear), CONSUMABLES, OBJECTS, AFFIXES, PROTIPS, KEYS, DADISMS, RECIPES, TRAPS_DEF, STATUSES, VENDORS, CLASSES.

## RULES FOR THE NIGHTLY RUN (read every time)
1. Do ONE unchecked chunk only, top-to-bottom, then stop.
2. PRIORITY ZERO: confirm all 7 JS files exist and parse. Run `node -e "const fs=require('fs');['js/config.js','js/sprites.js','js/data.js','js/game.js','js/render.js','js/ui.js','js/input.js'].forEach(f=>{if(!fs.existsSync(f))throw new Error('MISSING: '+f);}); console.log('files OK')"`. If broken, fix only that, run diagnostics, log it, stop.
3. After ANY data change, run `node tools_export_data.js` and confirm `data/*.txt` updated.
4. ALWAYS run the `## DIAGNOSTIC HARNESS (v0.5)`. It must print `ALL DIAGNOSTICS PASS`. If it fails and you can't fix within the chunk, revert your change so the game stays playable; leave the box unchecked with a note.
5. Modular JS architecture: 7 files in `js/` loaded in order. Sprites 16x16; every row 16 chars; every char in `PAL`.
6. Never rename/delete existing `id`s (creatures, bosses, items, classes, dadisms, vendors) — bestiary + saves depend on them. Only add.
7. Preserve the GBA-crisp look: world art on canvas, ALL UI text via DOM (never ctx.fillText for text). FOV must keep blocking sight past walls/closed doors.
8. NAMING (enforce in all new text): Dadisms (not spells), Book of Dadvice (not spellbook), Patience (not mana/moxie in UI), Pro Tips (not scrolls), Remedies (not potions), Upgrades (helpful affixes), Learning Experiences (harmful affixes). Match the comedic tone bible.
9. Append a dated line to `## CHANGELOG`.

⚠️ Editing note: the Edit tool has truncated this HTML before by writing from a stale buffer. Always Read the full file before editing; re-verify closing tags after each edit (`grep -c "</script>"`). For large changes, build in a temp file via bash heredocs and `cp` into place, then run the harness.
